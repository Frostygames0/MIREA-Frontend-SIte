Основные термины

Словарь понятий, которые встречаются при изучении любого языка программирования.

Словарь

Алгоритм
Конечная последовательность шагов, которая приводит к решению задачи.
API
Программный интерфейс: набор функций и правил, через которые одна программа обращается к другой.
Библиотека
Набор готового кода, который можно подключить к своему проекту, чтобы не писать всё с нуля.
Коллекция готовых функций и инструментов для решения типовых задач.
Git
Система контроля версий, которая хранит историю изменений файлов проекта.
IDE
Интегрированная среда разработки: редактор кода, отладчик и другие инструменты в одной программе.
Интерпретатор
Программа, выполняющая код построчно, без предварительной компиляции.
Компилятор
Компилятор — программа, переводящая исходный код в машинный код перед запуском.
Инструмент, который проверяет код на ошибки ещё до запуска программы.
Отладка
Поиск и исправление ошибок в программе.
Переменная
Именованная область памяти, в которой хранится значение.
Синтаксис
Набор правил, определяющих правильную запись инструкций на языке программирования.
Типизация
Способ, которым язык работает с типами данных: статическая (тип известен до запуска) или динамическая (тип определяется во время выполнения).
Фреймворк
Более крупная, чем библиотека, «заготовка» проекта со своей структурой и правилами.
Функция
Именованный фрагмент кода, который можно вызвать несколько раз с разными аргументами.
