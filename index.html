Примеры кода

Python

Простая программа «Hello, World!»:

print("Hello, World!") # комментарий: функция print выводит текст на экран

Особенности синтаксиса:
Отступы вместо фигурных скобок.
Двоеточие перед блоком кода.
Динамическая типизация переменных.

JavaScript

Тот же пример на JavaScript:

console.log("Hello, World!"); // комментарий: вывод текста в консоль браузера

Особенности синтаксиса:
Точка с запятой в конце строки (необязательна).
Фигурные скобки для блоков кода.
Выполняется прямо в браузере.

Сферы применения языков

  1. Python
    • Анализ данных и машинное обучение (NumPy, Pandas, TensorFlow)
    • Веб-разработка (Django, Flask)
    • Автоматизация и написание скриптов
  2. JavaScript
    • Фронтенд-разработка (React, Vue, Angular)
    • Серверные приложения (Node.js, Express)
    • Мобильные приложения (React Native)
  3. Java
    • Android-приложения
    • Корпоративные системы и банковское ПО
    • Большие серверные приложения
  4. C#
    • Разработка игр (Unity)
    • Десктопные приложения на Windows
    • Веб-сервисы на платформе .NET
  5. C++
    • Разработка игр (Unreal Engine)
    • Системное программирование и драйверы
    • Высокопроизводительные приложения
  6. C
    • Операционные системы
    • Программирование микроконтроллеров и embedded-систем
    • Драйверы устройств

Основные термины

Компилятор
Компилятор — программа, переводящая исходный код в машинный код перед запуском.
Инструмент, который проверяет код на ошибки ещё до запуска программы.
Интерпретатор
Программа, выполняющая код построчно, без предварительной компиляции.
Синтаксис
Набор правил, определяющих правильную запись инструкций на языке программирования.
Библиотека
Набор готового кода, который можно подключить к своему проекту, чтобы не писать всё с нуля.
Коллекция готовых функций и инструментов для решения типовых задач.
Фреймворк
Более крупная, чем библиотека, «заготовка» проекта со своей структурой и правилами.
