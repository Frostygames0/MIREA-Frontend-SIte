Здесь собраны краткие описания популярных языков программирования, примеры кода, словарь основных терминов и тест для самопроверки. Сайт поможет начинающему разработчику выбрать первый язык и понять, чем языки отличаются друг от друга.

Новости

NEW

Вышел Python 3.14

В октябре 2025 года вышла версия Python 3.14. В ней появились шаблонные строки (t-строки), отложенное вычисление аннотаций типов и официальная поддержка сборки интерпретатора без глобальной блокировки (GIL), которая позволяет потокам выполняться параллельно. Также улучшены сообщения об ошибках и интерактивная консоль: появилась подсветка синтаксиса.

Java 25 — новая LTS-версия

В сентябре 2025 года вышла Java 25 с долгосрочной поддержкой (LTS). Упрощено написание небольших программ: метод main теперь можно объявлять без класса и модификаторов. Окончательно добавлены scoped values — безопасная замена ThreadLocal для виртуальных потоков, а также гибкие тела конструкторов.

C# 14 и .NET 10

В ноябре 2025 года вместе с платформой .NET 10 вышел C# 14. Главные нововведения — расширенные члены (extension members), ключевое слово field для свойств и новые возможности работы с Span. .NET 10 также является LTS-выпуском и будет поддерживаться три года.
