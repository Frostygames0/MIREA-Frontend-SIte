Примеры кода

Одна и та же задача — вывести приветствие и посчитать сумму чисел от 1 до 10 — на шести языках. Так легче сравнить их синтаксис.

Выберите язык

Python

Вывод строки «Hello, World!» и сумма чисел от 1 до 10:

print("Hello, World!")

total = 0
for i in range(1, 11):
    total += i
print("Сумма:", total)

Особенности синтаксиса:

  • Отступы вместо фигурных скобок.
  • Двоеточие перед блоком кода.
  • Динамическая типизация переменных.
Подробнее о языке Python →

JavaScript

Вывод строки «Hello, World!» и сумма чисел от 1 до 10:

console.log("Hello, World!");

let total = 0;
for (let i = 1; i <= 10; i++) {
    total += i;
}
console.log("Сумма:", total);

Особенности синтаксиса:

  • Точка с запятой в конце строки (необязательна).
  • Фигурные скобки для блоков кода.
  • Выполняется прямо в браузере.
Подробнее о языке JavaScript →

Java

Вывод строки «Hello, World!» и сумма чисел от 1 до 10:

public class Main {
    public static void main(String[] args) {
        System.out.println("Hello, World!");

        int total = 0;
        for (int i = 1; i <= 10; i++) {
            total += i;
        }
        System.out.println("Сумма: " + total);
    }
}

Особенности синтаксиса:

  • Весь код находится внутри классов.
  • Тип переменной указывается явно.
  • Программа компилируется в байт-код для JVM.
Подробнее о языке Java →

C#

Вывод строки «Hello, World!» и сумма чисел от 1 до 10:

Console.WriteLine("Hello, World!");

int total = 0;
for (int i = 1; i <= 10; i++)
{
    total += i;
}
Console.WriteLine($"Сумма: {total}");

Особенности синтаксиса:

  • Программу можно писать без явного класса Main.
  • Интерполяция строк через символ $.
  • Фигурные скобки обычно переносят на новую строку.
Подробнее о языке C# →

C++

Вывод строки «Hello, World!» и сумма чисел от 1 до 10:

#include <iostream>

int main() {
    std::cout << "Hello, World!" << std::endl;

    int total = 0;
    for (int i = 1; i <= 10; i++) {
        total += i;
    }
    std::cout << "Сумма: " << total << std::endl;
    return 0;
}

Особенности синтаксиса:

  • Подключение библиотек через #include.
  • Вывод через поток std::cout и оператор <<.
  • Программа компилируется в машинный код.
Подробнее о языке C++ →

C

Вывод строки «Hello, World!» и сумма чисел от 1 до 10:

#include <stdio.h>

int main(void) {
    printf("Hello, World!\n");

    int total = 0;
    for (int i = 1; i <= 10; i++) {
        total += i;
    }
    printf("Сумма: %d\n", total);
    return 0;
}

Особенности синтаксиса:

  • Форматированный вывод через printf.
  • Нет классов и объектов.
  • Ручное управление памятью.
